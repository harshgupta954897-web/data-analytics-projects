# E-Commerce Sales Analysis Using SQL

## Project Overview
This project analyzes e-commerce sales data using MySQL to understand sales performance, product revenue, customer spending, and order trends.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Dataset
The project uses three tables:
- **Customers:** Customer details, city, age, and gender.
- **Products:** Product names, categories, and prices.
- **Orders:** Order details, quantities, and order dates.

## Key Analysis
- Total orders and total customers
- Total revenue and average order value
- Best-selling products by quantity
- Highest-revenue products
- Category-wise and city-wise revenue
- Month-wise sales and order trends
- Gender-wise customer analysis
- Customer-wise spending
- Customer order frequency
- High-value order analysis

## SQL Concepts Used
- CREATE DATABASE and CREATE TABLE
- INSERT and SELECT
- WHERE and ORDER BY
- JOIN
- GROUP BY
- Aggregate functions: SUM, COUNT, and AVG
- Date functions
- LEFT JOIN

## Project Goal
The goal is to practice SQL and generate useful business insights from e-commerce sales data.
